# Atelier — Climate Intelligence

A responsive carbon emissions monitoring dashboard concept with a luxury-inspired visual style. It presents emissions metrics, a reduction trajectory, emissions sources, operational hotspots, and prioritized net-zero recommendations.

## Preview

Open `index.html` in a browser, or visit the deployed Vercel URL.

## Features

- Carbon footprint and Scope 1 & 2 metrics
- Renewable electricity and 2030 target progress indicators
- Monthly emissions trajectory chart
- Emissions breakdown by source
- Operational hotspots
- Prioritized decarbonization recommendations
- Responsive layout for desktop and mobile
- Print-friendly report export
